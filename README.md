매주 자동으로 모아 한 장짜리 웹페이지로 정리합니다.

기계 · 전기 · 전자 · 용접 · 시설 계열을 대상으로 합니다.

**👉 최신 공고 보기 : https://hongyul67-cpu.github.io/gojol-chaeyong/**

## 무엇을 담고 무엇을 버리나

**담는 것**

- 학력요건에 **고졸**이 들어간 공고 (고졸 전용 + 고졸·대졸 병행)
- **채용구분이 신입**인 것
- 계열이 **기계 · 전기 · 전자 · 용접 · 시설** 중 하나라도 걸리는 것

**버리는 것**

- 육아휴직·병가 대체인력
- 비정규직(기간제·촉탁 등)
- 사무 계열 (기본값 꺼짐)
- 간호·보건·연구 등 무관한 계열

## 설정 바꾸기 (`collect.py` 맨 위)

공고가 '기계'라고 딱 적어 주는 일은 오히려 드뭅니다.
**시설·차량·설비·배관**처럼 공업 계열이 지원할 수 있는 표현을 낱말 표로 훑습니다.
**낱말을 넣고 빼는 것만으로 검색 범위가 바뀝니다.**

```python
TAG_KEYWORDS = { "기계": [...], "전기": [...], "전자": [...],
                 "용접": [...], "시설": [...], "사무": [...] }

CORE_TAGS = {"기계", "전기", "전자", "용접", "시설"}
INCLUDE_SAMU = False     # True 로 바꾸면 고졸 전용 사무직도 담김
```

낱말을 넓히면 엉뚱한 공고도 걸립니다.
예전에 `무기계약직` 안의 '기계' 때문에 병동 업무직이 기계직으로 잡힌 적이 있어,
지금은 고용형태 표현을 먼저 지우고 판단합니다. 낱말을 추가하면 한 번 돌려보고 확인하세요.

## 표에 자동으로 채워지는 것

| 열 | 어떻게 정하나 |
|---|---|
| **직렬태그** | 공고의 모집분야에서 계열 낱말을 뽑아냄 |
| **대상** | 응시자격 문구로 판단 — `재학생` / `졸업생` / `공통` / `확인필요` |
| **학교장추천** | 응시자격에 추천 관련 문구가 있으면 `필요`. 근거 문장이 `비고`에 들어감 |
| **접수시작·접수마감** | 채용기간을 날짜로 쪼갬 |
| **상태** | 접수마감 기준 `마감` / `임박`(7일 이내) / `진행중` |
| **공고링크** | 기관 채용 사이트. 없으면 잡알리오 상세 주소 |

**대상과 학교장추천은 문구로 추정한 값입니다.**
학교장 추천 마감일·제출서류·세부 자격요건은 잡알리오에 실려 있지 않습니다.
